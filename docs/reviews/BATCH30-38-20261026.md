# batch29 → batch38 源码与验证范围

本轮追加20份有序补丁，保留前93份；最终公开系列113份，35个定制项目。中间批次标签记录源码演进，不代表每个中间批次均形成发布产物。

- 新增双频 Wi-Fi 连接开关：条件满足时同时连接同一网络的 2.4GHz 与 5GHz；默认关闭，不保证普通应用自动叠加带宽。
- 修正 GMS 版本中未设置过的 GMS 开关默认值，保留用户已有选择。
- 改善横屏游戏中从侧边栏打开竖屏应用的小窗布局，统一窗口比例与控制条；修正控制条归属、双窗口切换、无法关闭、重复最近任务和表面残留等问题。
- 修复 Termux 等应用小窗中返回手势无法收起键盘，完善取消手势及迟到动画回调处理。
- 修复最近任务侧滑返回失效，以及隐藏导航条后返回桌面时误触 QQ 底部切页的问题。
- 改善 ZIP 附件等文件跨应用打开时的授权传递，完善安装审批结果与调用者身份处理。
- 完善安装失败时的会话清理和错误提示；设备保护状态作为上下文显示，不把其他安全拒绝武断归因为 FRP，保留原安全检查。
- 修正杜比解码服务的系统接口兼容性，改善小窗切换场景下的检测兼容性。
- 完善用户存储准备失败的诊断分类，保留子进程原始负错误码。

## 验证依据

- 最终小窗/IME修正：11组主机套件479条断言与8组旧实现负对照；追踪真实任务身份、异步转场、取消及迟到回调。Android任务调度和SurfaceFlinger仍由主机替身模拟。
- 最终诊断修正：23安装器场景104断言、27子目录状态场景133断言、9UI场景47断言，共59场景284断言；2组可执行故障变体和2组旧因果文案静态检查。
- 实际PackageInstaller/vold/vold_prepare_subdirs完成生产模块编译链接，检查javap、R8映射后DEX、中英文APK资源、ARM64 ELF与Windows回读；未使用测试替身代替正式链接。
- batch38两版均完成签名、OTA/payload、实际分区镜像、组件快照及Windows回读。每版boot核对其自己的签名payload。

GMS 与 Vanilla 均完成整包构建、既有身份签名、实际镜像/OTA/payload 审计、组件一致性及 Windows 独立回读。
维护者在 12T Pro GMS 上反馈实测暂未发现问题；本次没有逐项由构建端独立复核全部手机测试。
Vanilla、K50 Ultra 尚无本批独立手机验收；LHDC 缺兼容耳机，OFRP PIN 解密、扩展 USB 等场景仍需对应验证。
不能把 12T Pro 的结果推广为 K50 Ultra 全面通过，也不声称长期稳定性或所有硬件组合已验证。

公开可运行的诊断回归见 tests/failure-diagnostics-regressions.py，适配了路径入口并保留原有断言。更早主机证据不等于当前手机逐项独立验收。
安装器仅说明framework报告的设备保护状态，不从异常文本或GMS开关推断原因，不跳过认证。存储诊断不把负errno当作确定信号或OOM。
小窗动画取消等未确认推演没有直接列为生产故障；用户反馈在未建立根因前作为调查线索，不列为已知ROM缺陷。
