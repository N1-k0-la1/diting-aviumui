# 指纹与蓝牙修复 · batch28 / batch29

## 生产修复

- CR-1：初始化 HAL 指针；打开失败时清理资源并拒绝建立不可用会话。
- CR-4：同步会话指针，回调执行期间保留会话对象的生命周期。
- CR-2：在同一 HAL 实例中按用户共享锁定状态，衔接会话重建与定时锁定解除；恢复定时器时保留已到期状态，直到发出解除回调。
- CR-5：蓝牙能力列表或选定编解码能力缺失时，对话框只保留默认选项。

增量补丁在 patches/batch28-20261018/，公开系列第 91、92 份。batch29 继续包含这些修复。
